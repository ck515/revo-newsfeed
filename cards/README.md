# REVO ニュースカード レンダラー

1080×1350 の Instagram フィード用カードを PNG で出力します。手動投稿前提の納品物として使えます。

```
cards/
├── render.py       … render_card() / render_cards()
├── template.html   … カードの HTML + CSS（デザインはここ）
├── fonts/          … Saira Condensed / Noto Sans JP（同梱・オフライン動作）
└── out/            … 出力先
```

## 依存

```bash
pip install playwright budoux
playwright install chromium
```

フォントはバンドル済みなので、システムに何も入れる必要はありません。

## 使い方

```python
from render import render_card

render_card(
    headline="新型シビックタイプR、マイナーチェンジで出力向上",
    category="DEBUT",
    keywords=["シビックタイプR", "ホンダ", "JDM"],
    date="2026-08-18",
    out="out/civic.png",
)
```

複数枚（月次イベントまとめのカルーセル、ニュースの日次バッチ）:

```python
from render import render_cards

render_cards([
    {"name": "01_cover", "headline": "9月のカーイベント", "category": "EVENT", "date": "2026-09-01"},
    {"name": "02_kuhl",  "headline": "KUHL 大感謝オフ会2026", "category": "EVENT", "keywords": ["富士スピードウェイ"]},
], out_dir="out/202609")
```

`name` を `01_` `02_` と振ると、アップロード時の並び順が固定されます。

CLI:

```bash
python render.py --headline "GT-Rの生産終了、40年の歴史に幕" \
  --category RETRO --keywords GT-R 日産 絶版車 --date 2026-08-18 --out out/gtr.png
```

## 引数

| 引数 | 内容 |
|---|---|
| `headline` | 日本語見出し。**34文字以内**推奨（それ以上は文字が小さくなりフィードで読めない） |
| `category` | `DEBUT` `PARTS` `EVENT` `RACE` `RETRO` または任意文字列。**4〜6文字に収めること** |
| `keywords` | 最大3件。先頭の `#` は任意 |
| `date` | `YYYY-MM-DD`（`MM.DD` で表示）または任意文字列 |
| `photo` | 任意。ローカル画像パス。全面背景として敷かれる。**権利クリアな素材のみ** |
| `overlay` | 黒オーバーレイの濃度 0〜1（既定 0.42）。明るい／情報量の多い写真では上げる |
| `logo_color` | `white`（既定）／ `accent` |

## デザイン

デザインシステムに準拠しています。

- 背景 `#0A0A0B` ／ カード `#16161A` `#1D1D22` ／ ボーダー `#26262B` ／ アクセント `#F5D547`（唯一のアクセント）
- 英数ディスプレイ: Saira Condensed Black（斜体は skewX で付与。Saira Condensed に italic ファイルは存在しないため）
- 日本語: Noto Sans JP 900 / 500

シグネチャは左上のオブリークタグとリベリーストライプ。プロフィールの 1:1 グリッドクロップ内に収まる位置（top 158px）に置いてあるので、グリッド一覧でも識別できます。

## 実装上の注意

**下揃え** — 見出し・アクセントルール・ハッシュタグは、写真の有無にかかわらずボックスの下端に揃います。カード間でハッシュタグのベースラインが一致するので、フィードに連続して並んだときの見え方が安定します。余白は常に上に出ます。

**見出しの自動サイズ調整** — 116px から 42px まで段階的に縮小し、テキストブロックが枠に収まる最初のサイズを採用します。テキストブロックは下揃えなのではみ出しが上方向に出ます。`scrollHeight` では検出できないため、要素高さを直接測っています（`template.html` の `contentHeight()`）。ここを `scrollHeight` に戻すと縮小が効かなくなります。

**フォント読み込みの待機** — 組みの判断はすべて実測なので、スクリプト全体を `document.fonts.ready` で待たせています。これを外すとフォールバックフォントの指標で計算され、その後レイアウトが静かに崩れます（実測とスクリプトの値が0.004対0.172まで乖離しました）。**ここは絶対に外さないでください。**

**写真** — 任意です。デフォルトはタイポグラフィのみ。メディア制作の写真は使用不可。メーカー公式・パーツメーカー公式・主催者提供素材に限ります。

指定した場合はカード全面（1080×1350）に敷かれ、上に黒の半透過オーバーレイが乗ります。オーバーレイは2層構成で、`--overlay` のフラットなスクリム（既定 0.42）と、下方向に濃くなるグラデーション（0 → 0.58）の合成です。白文字の可読性は下段で確保されます。

明るい写真や背景がうるさい写真では `overlay=0.55` 程度まで上げてください。逆に暗い夜間の写真なら 0.3 まで下げられます。

**タイプスケール** — 76px から 38px まで。以前は 116px まで上げていましたが、1行あたり7〜8文字にしかならず改行が破綻したため下げました。76px で1行13〜14文字になり、日本語の見出しとして読める密度になります。見出しが短いカードは余白が多めに残りますが、カード間の一貫性を優先しています。

**速度・ペース・順位のデータはカードに入れないこと。** App Store 審査履歴からのハード制約で、UI・シェア画像・保存データすべてに適用されます。

## 横詰めと改行のルール

### 適用順序

見出しの組みは4段階で決まります。上から順に試し、成立した時点で確定します。

1. **palt（プロポーショナルメトリクス）** — 常時ON。仮名と約物の左右アキを詰めます。実測で**幅が11%縮みます**（1847px → 1644px）。ここが一番効くので、まずこれで足ります
2. **サイズ** — 76px → 38px の9段階。大きい方を優先
3. **横詰め（トラッキング）** — -0.005em → -0.065em の5段階。日本語の組版はサイズを落とす前に字間を詰めるので、同じサイズで詰めて収まるならそちらを採る
4. **追い込み** — 最終行が1〜2文字なら、サイズを落とさず -0.085em まで詰めて前の行に引き上げる

`text-wrap: balance` も併用しています。ChromiumのbalanceはCJKでも機能し、これが行長の均一化の主力です。

| text-wrap | 平均ラグ（8ケース実測） |
|---|---|
| **balance** | **8.8%** |
| pretty | 20.5% |
| 指定なし | 20.5% |

balanceを切ると横詰めが頻繁に発火しますが、結果は悪化します（70%のラグが出るケースあり）。**balanceは外さないでください。**

### 改行位置（BudouX）

Chromiumは日本語をほぼ任意の位置で折るため、正規表現だけでは `富/士`、`開/催`、`大/感謝` のような語中分割を防げません。語境界の判定が必要なので、**BudouX**（Googleの日本語改行モデル）を使っています。

```
走行会は | 8月23日に | 富士スピードウェイで | 開催、 | 参加費は | 5000円で | エントリーは | 公式サイトから
```

各フレーズを `white-space:nowrap` で包み、改行がフレーズ境界にのみ落ちるようにします。BudouXが未インストールの場合は正規表現のみにフォールバックします（`_PARSER is None`）。

`pip install budoux` が必要です。

### フレーズ幅の上限

フレーズがカラムより広いと溢れるので、`PHRASE_LIMIT`（0.85）を超えたフレーズは保護を解除し、内部で折れるようにします。その際も正規表現による保護が二次防御として残るため、日付や英単語は保たれます。

保護の階層:

| 階層 | 対象 | 許容幅 |
|---|---|---|
| 1次 | BudouXフレーズ | 0.85 |
| 2次 | 数値・助数詞 | 0.86 |
| 2次 | 英単語 | 0.68 |
| 2次 | カタカナ語 | 0.38 |

`PHRASE_LIMIT` を 0.62 まで下げると右端は揃いますが、`マイ / ナーチェンジ` のような語中分割が復活します。**0.85を下げないでください。**

### 禁則処理

行頭禁則（`、。」』）`など）と行末禁則（`「『（`など）は**Chromiumがnativeで処理する**ので実装していません。`line-break: strict` を指定済みです。検証済みの挙動:

```
開催決定「大感謝オフ   ← 「 が行末に残らない
会」が富士で行われる   ← 」 が行頭に来ない
予定
```

### ラグ調整をしない理由

改行がBudouXのフレーズ境界に乗った後は、字間を詰めて右端を揃える処理を**意図的に入れていません**。字詰めは改行位置を動かすので、正しい語境界を犠牲にして右端の見た目を買う取引になります。

日本語の見出しは元々ラグ付きで組みます。**最終行が短いのは正常、語中で折れているのは異常**という優先順位です。

最終行が1〜2文字の場合のみ、追い込み（-0.085emまでの字詰め）で前の行に引き上げます。

## カテゴリ

| キー | 対象 |
|---|---|
| `DEBUT` | 新型車の発表・改良 |
| `PARTS` | パーツ・チューニング |
| `EVENT` | イベント・オフ会・走行会 |
| `RACE` | モータースポーツ |
| `RETRO` | 旧車・絶版車・市場動向 |

**受け皿カテゴリは意図的に置いていません。** ニュースアカウントでは全投稿がニュースなので汎用ラベルは情報量ゼロです。5つのどれにも入らない記事は、ラベルを付けるのではなく**不採用にする**のが正しい判断です。

タグには `min-width: 168px` を指定しています。4文字の `RACE` も5文字のラベルと同じ幅で出るので、プロフィールのグリッドで一貫した印になります。カスタムラベルを使う場合も4〜6文字に収めてください。7文字以上はタグが伸びてグリッドの統一が崩れます（`MOTORSPORT` で290pxまで伸びます）。

採点プロンプト側の `category` の enum も同じ5値に揃えてください。ずれると全件がフォールバックします。
