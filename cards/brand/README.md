# ブランドマーク

`logo.png` をこのフォルダに置くと、**全レイアウトのフッターが自動でその画像に差し替わります。** ファイルが無い場合は Saira Condensed で組んだ `REVO` の文字にフォールバックするので、用意ができるまで運用は止まりません。

```
cards/brand/
└── logo.png      ← ここに置く
```

`logo.svg` `logo.webp` `logo.jpg` も使えます。この順で最初に見つかったものが採用されます。

## 素材の条件

**背景透過のPNG。** カードは黒地で、表紙では写真の上に直接乗るため、白い背景が付いていると四角く浮きます。

**横長の切り抜き。** 高さ56pxで表示され、幅は縦横比に応じて自動で決まります。上下に余白の入った画像だとロゴ本体が小さくなるので、余白は詰めた状態で書き出してください。

**明るい色。** 黒背景の上に置くので、白または `#F5D547` を基準に。暗い色のロゴは沈みます。

推奨サイズは高さ200px以上（Retina想定で余裕を持たせるため）。

## 高さの調整

シンボル付きのロックアップだと、文字だけのワードマークより大きく見せたい場合があります。`brandmark.py` の `LOGO_HEIGHT`（既定56）で変えられます。

```python
LOGO_HEIGHT = 64
```

## 傾きについて

タイプで組んだ `REVO` は、リベリーのストライプに合わせて `skewX(-11deg)` を掛けています。**画像ロゴには傾きを掛けません。** 完成したロゴは既に固有の角度を持っており、その上からさらに傾けると意匠が歪むためです。

ロゴ側に傾きを入れたい場合は、書き出す前のデータで角度を付けてください。
